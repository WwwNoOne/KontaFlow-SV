# KontaFlow-SV

Programa para automatizar el ciclo contable de empresas de El Salvador. El proyecto plantea una app propia sobre Frappe y ERPNext, con ingesta de documentos tributarios electrónicos (DTE), contabilidad determinista e IA para asistir al contador en tareas ambiguas.

## Empieza aquí

1. Abre esta carpeta como directorio de trabajo en Claude Code y Codex.
2. Lee el [tablero de arranque](docs/ARRANQUE.md) para ver el estado, la primera tarea y los mensajes para iniciar ambas sesiones.
3. Consulta el [contexto técnico](Project_Context.md) para la visión completa y [AGENTS.md](AGENTS.md) para las reglas de trabajo compartidas. [CLAUDE.md](CLAUDE.md) carga esas reglas en Claude Code.

KontaFlow SV está en fase de arranque. Los repositorios vecinos `erpnext/` y `Oculus/` son referencias separadas dentro de `KF_Workspace/`. Oculus aporta ejemplos para la ingesta de compras desde correo y archivos. La app nueva tendrá que admitir también la carga manual de documentos.
