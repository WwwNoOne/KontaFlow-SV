# KontaFlow-SV

Programa para automatizar el ciclo contable de empresas de El Salvador. El proyecto plantea una app propia sobre Frappe y ERPNext, con ingesta de documentos tributarios electrónicos (DTE), contabilidad determinista e IA para asistir al contador en tareas ambiguas.

## Empieza aquí

1. Abre el worktree activo del producto como directorio de trabajo.
2. Lee el [contexto actual](docs/CONTEXTO_ACTUAL.md) y el [tablero](docs/ARRANQUE.md).
3. Consulta las [notas de coordinación](docs/Cordinacion.md), las [reglas compartidas](AGENTS.md) y la [visión original](docs/Project_Context.md).

Los repositorios vecinos `erpnext/` y `Oculus/` son referencias separadas dentro de `KF_Workspace/`. La [guía de desarrollo local](docs/DESARROLLO_LOCAL.md) explica cómo ejecutar la app y sus pruebas.
